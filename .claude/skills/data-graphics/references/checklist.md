# 仕上げチェックリスト

表・グラフ・タイムラインを組み込んだ後、`slide-deck-html` の機械チェック（[../../slide-deck-html/references/slide-rules.md](../../slide-deck-html/references/slide-rules.md) §4）に加えて以下を確認する。

## データの正しさ

- [ ] 数値は実データから取っている（プレースホルダー・架空の数字が残っていない）
- [ ] 部分の合計が全体（100%やトータル値）と一致している
- [ ] 単位・小数点の桁数がページ内で統一されている
- [ ] 軸を0から始めている（棒グラフ・面グラフで長さを比較させる場合）

## デクラッター

- [ ] 枠線・グリッド線・凡例のうち、無くても読めるものを削った
- [ ] 系列名・最終値を凡例ではなく図形の近くに直接置いた
- [ ] アクセントカラーは1〜2箇所（伝えたい1点）に絞られている
- [ ] 円グラフ・ドーナツは4区分以内。5区分超は棒グラフに置き換えた
- [ ] デッキ内で同じチャート種類（棒グラフ等）だけを繰り返していないか。データの関係性が変わったら[charts.md](charts.md)／[diagrams.md](diagrams.md)から適切な型に変えたか

## アクセシビリティ

- [ ] 色だけで系列・区分を区別していない（形・パターン・直接ラベルを併用）
- [ ] `<svg>` に `role="img"` と内容を説明する `aria-label` を付けている
- [ ] テキストと背景のコントラストが十分（薄いグレー文字を小さいサイズで使っていないか）

## スライドとの整合

- [ ] タイトル・本文の主張と、図が実際に示している数値・傾向が一致している（So what が図に対応している）
- [ ] `viewBox` のまま拡大縮小してもステージ（1600×900）からはみ出さない
- [ ] 動きを足した場合、`svg-story-animation` のチェックリストも別途通している
- [ ] 表の行数・グラフの系列数・タイムラインの項目数が、密度モード（講演用は少なく／配布用はやや多めまで）に合っている
