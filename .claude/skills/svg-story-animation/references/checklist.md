# 実装後チェックリスト

supermemoryai/skills の `svg-animations`（MIT License）が挙げるベストプラクティスを踏まえた、実装後の確認項目。

## 意味があるか（このプロジェクト独自の観点）

- [ ] アニメーションを止めて最終フレームだけを見せても、伝えたい結論が伝わるか（＝アニメーションが情報を隠していないか）
- [ ] 同時に動いている要素は3〜4個以内か
- [ ] 1つのアニメーションが1つの仕組み（収束／パルス／変換／循環／成長／分岐／進行）を表しているか。複数の仕組みを1つの図に詰め込んでいないか

## 技術的な健全性

- [ ] `viewBox` を指定しているか（`width` / `height` の固定値に依存していないか）
- [ ] グラデーション・フィルタ・マスク・繰り返し図形は `<defs>` にまとめているか
- [ ] シェイプモーフィングをしている場合、変形前後の `d` のコマンド数・種類・順序が一致しているか
- [ ] 複数のSVGを同一HTML内にインライン埋め込みしている場合、`<style>` 内のクラス名や `id` が衝突していないか（別々の素材から来たSVGは、クラス名・idに接頭辞を付けて名前空間を分離する）
- [ ] `transform` / `opacity` 中心のアニメーションになっているか（頻繁な `x`/`y`/`width`/`height` の直接アニメーションを避けられているか）

## アクセシビリティ

- [ ] 装飾目的のSVGには `aria-hidden="true"` を、意味を持つ単体の画像として使うSVGには `role="img"` と `<title>` を付けているか
- [ ] `prefers-reduced-motion: reduce`環境で、SMILアニメーションを一時停止する処理を入れているか（`svg.pauseAnimations()`、または該当要素の `animation-play-state` 制御）

## パフォーマンス

- [ ] ループ時間は2.5〜5秒程度で、せわしなく感じないか
- [ ] 1ページ内のインラインSVGとアニメーション要素の総数が、体感速度に影響するほど多くなっていないか
