# ビジュアルAI臭語彙集（見た目の「量産テンプレ感」を消す）

[vendored/ai-smell-lexicon.md](vendored/ai-smell-lexicon.md)（文章のAI slop）の視覚版。文章と同じ理由——**一見丁寧だが中身のない体裁の積み重ねが量産感を生む**——が、見た目にもそのまま当てはまる。作成後・納品前に本ファイルで30秒セルフチェックする。

## 0. 実際にこのプロジェクトの成果物で見つかった核

実際に生成されたデッキ（`output/`配下）をレビューして判明した、最も頻度の高い問題。

- **全ページ同一の左テキスト・右ビジュアル2カラムテンプレートの反復** → [layout-gallery.md](layout-gallery.md)で型を混ぜる
- **unDraw等の汎用フラットイラストの多用**（配色をブランドカラーに変えても構図・ポーズが汎用のまま） → `svg-story-animation`の[illustration-styles.md](../../svg-story-animation/references/illustration-styles.md)
- **「点と線のネットワーク」抽象背景を毎ページに使い回す** → ヒーロー・クロージングなど1〜2箇所に限定する
- **角丸四角＋ベタ塗りピクトグラムのアイコンタイルの多用**（同じ意匠が4回以上登場する） → カスタムのモノラインアイコンにするか、アイコンなしで文字だけに置き換える

## 1. レイアウト

- 全ページが同じグリッド・同じ余白・同じ図の置き場所の繰り返し（[layout-gallery.md](layout-gallery.md)で型を切り替える）
- カード＋ソフトドロップシャドウ＋大きめ角丸の乱用（フレームワークの初期値をそのまま使った既視感） → [design-system.md](design-system.md)の角丸・シャドウ規律を守る
- 中央揃え一辺倒（非対称なレイアウトが1ページもない）
- 装飾チップ・帯・フローティングラベルを図の構造の外に浮かせて置く（[slide-rules.md](slide-rules.md) §2-6と同根）

## 2. イラスト・アイコン

- ストックのフラット人物イラスト（unDraw / Storyset等）をリカラーしただけで使う
- 絵文字をアイコン代わりに使う
- 信号機3色（赤／黄／緑）での状態表現
- 同じアイコン意匠（角丸四角＋ベタ塗りピクトグラム）をデッキ内で4回以上使い回す
- 中心のSVGアニメーションの線幅・角の丸めと、周辺のアイコン・装飾の意匠が揃っていない（別々の素材を継ぎ接ぎした印象になる）

## 3. 配色・背景

- 紫→青の汎用グラデーション背景（「テック系スタートアップのランディングページ」感の典型）
- アクセントカラーが3色以上使われ、結局どこを見ればいいか伝わらない
- パステル全体・低コントラストで、階層がフォントサイズの大小だけに依存している

## 4. データ表現

- 円グラフの多用、5区分を超える円グラフ
- 凡例だらけで直接ラベリングがない
- 3D風の棒・ドーナツ
- チャート種類が毎ページ同じ（棒グラフしか使っていない） → `data-graphics`の[charts.md](../../data-graphics/references/charts.md)／[diagrams.md](../../data-graphics/references/diagrams.md)で伝えたい関係性に合った型を選ぶ

## 5. アニメーション

- 同じ視覚パターン番号を3回以上使い回す（`svg-story-animation`の[storytelling-patterns.md](../../svg-story-animation/references/storytelling-patterns.md)「概念→パターン早見表」参照）
- すべてのページの動きが同じ速度・同じイージングで、緩急がない

## 6. 30秒セルフチェック（仕上げ・納品前）

1. デッキ内でレイアウトの型（[layout-gallery.md](layout-gallery.md)の番号）を数え、同じ番号が3ページ以上連続していないか
2. 人物イラストの構図・スタイルが汎用ストックのままになっていないか
3. 装飾（背景のネットワーク・アイコンタイル）が全ページで同じものの反復になっていないか
4. アクセントカラーが1〜2色に絞られているか（デッキ全体のUIチロムも含めて）
5. 中心図の視覚パターン・チャート種類がページごとに変化しているか
6. 「これはどこかで見たことがある」という既視感がないか——既視感があれば大抵、上のどれかに当てはまる

## 運用

指摘を受けたら本ファイルに1行追記する（`vendored/ai-smell-lexicon.md`と同じ蓄積運用）。[review-prompt.md](review-prompt.md)のフレッシュアイ・レビューでも、体裁だけでなくこの語彙集の観点（型の使い回し・イラストの汎用感）を確認対象に含める。
